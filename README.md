🎹 Mini Synth Piano

A small, aesthetic piano inspired by a modern synth UI.
Only the black and white keys are functional and play local .mp3 sound files.

🚀 Features

Functional black + white piano keys

Local MP3 sound support (/sounds folder)

Clean dark synth-style UI (inspired by hardware design)

Simple, easy-to-understand HTML + CSS + JS

Keyboard support (A–K + W/E/T/Y/U for black keys)
